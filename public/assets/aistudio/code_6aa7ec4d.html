Flujo Formativo Transaccional (ACID)

El sistema desacopla intencionalmente el registro comercial del cobro en metálico:

1. Vendedor crea venta preliminar en estado PENDIENTE.
2. Cajero valida saldo y confirma el cobro solo si su Caja está Abierta.
3. Transacción PDO::beginTransaction() descuenta el stock atómicamente.
4. Comprobante de factura inmutable generado para impresión fiscal.
Patrón: Separación de Responsabilidades InnoDB Engine
